# AD266 - Agentic UI development with SAPUI5 and how it relates to Joule Work

[![REUSE status](https://api.reuse.software/badge/github.com/SAP-samples/teched2026-AD266)](https://api.reuse.software/info/github.com/SAP-samples/teched2026-AD266)

## Description

This repository contains the material for the SAP TechEd 2026 session **AD266 - Agentic UI
development with SAPUI5 and how it relates to Joule Work**.

## Overview

This session teaches you to use **Claude Code CLI** equipped with the **UI5 plugins for coding agents** as a productivity multiplier across the full lifecycle of a SAPUI5 project. You will **create and enhance** a new SAPUI5 application,
**convert** it to TypeScript and **modernize** a legacy application.

The emphasis is not "let the AI do it" but **"drive the AI well"**: how UI5-specific tooling
grounds the coding agent in the real API reference, the linter, and the official guidelines so its
output is correct, current, and best-practice-compliant — and how you review and verify what it
produces.

> **Your prompts, your pace.** Each exercise includes example prompts you can use directly or adapt as a starting point. Feel free to write your own prompts entirely. The goal is to get comfortable driving the agent yourself, not to copy-paste a fixed script.

## Requirements (already present at the TechEd machines)

- **Node.js** LTS (v22+) and **Git**.
- A **terminal** (macOS Terminal, iTerm2, Windows Terminal, or any shell).
- Basic familiarity with SAPUI5 concepts (views, controllers, models, manifest).

Any editor can be used alongside the terminal to inspect generated code, but all agent
interactions happen in the CLI.
